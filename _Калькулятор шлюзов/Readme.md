Что это такое?  
Это калькулятор шлюза по умолчанию, который высчитывается на основе маски подсети. Написан на PowerShell.  

1) Работает без прав администратора.  

2) Минимально рекомендуемая версия PowerShell 5.1 (Windows 10 / 1809).    

3) Принудительно выставлена кодировка UTF-8, она прописана в самом верху скрипта.  

4) Скрипт крутится в бесконечном цикле, ничего перезапускать не нужно.  

5) Поддерживает очистку экрана по командам cls и clear.  

6) Поддерживает логирование по команде history. Её можно вводить в любом регистре.  
Она помнит до 100 введённых команд.  

7) Для более удобного запуска, написан небольшой батничек, дабы не копировать весь код в PowerShell,  
хотя можно запускать и из него. Батничек цепляет powershell-скрипт непосредственно из той папки  
в которой находится. Просто двойной клик по нему и поехали!  

8) При запуске через PowerShell 7.6.7 могут быть проблемы с кодировкой.  
Если запускать файл .ps1 по ПКМ через PowerShell 7.6.7 - покажет знаки вопроса.  
Если запускать файл .ps1 по ПКМ через PowerShell 5.1 - всё ок.  
Если тупо копировать скрипт в PowerShell 7.6.7 - тоже всё ок.  
Притом не важно, делаем мы это от админа, или нет. Почему так - непонятно, все кодировки выставлены ровно.
