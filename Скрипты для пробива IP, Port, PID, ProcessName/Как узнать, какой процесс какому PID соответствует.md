Как узнать, какой процесс какому PID соответствует ?  
Например, для PID 8416:  

```  
Get-Process -Id 8416 | Select-Object Id,ProcessName,Path  
```  

// Если мы знаем название проги, но не знаем PID, то его PID можно вычислить вот так:  

```  
Get-Process [название программы]  
```  

// Смотрим столбец "id".
