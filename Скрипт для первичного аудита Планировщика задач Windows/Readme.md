Что это такое?  

Это скрипт для первичного аудита Планировщика задач Windows на потенциально подозрительные задания.  

* получает все Scheduled Tasks;  
* исключает задачи, путь которых начинается с \Microsoft\;  
* ищет среди оставшихся задачи, которые запускают cmd, powershell, .exe, .bat, wscript, cscript и т.п. ;  
* показывает, что именно запускается и с какими аргументами;  
* НО! он не определяет, что задача является вредоносной. Он только выделяет задачи, которые стоит проверить.  

Что показывает?  

TaskPath — путь задачи в Планировщике.  
TaskName — название задачи.  
Execute — какой файл запускается.  
Arguments — параметры запуска.  
User — от имени кого запускается.  
RunLevel — уровень привилегий.  

Это хороший первичный фильтр Scheduled Tasks, но не полноценная антивирусная проверка.  

Как пользоваться?  

Открываем PowerShell от админа, кидаем туда скрипт, нажимаем Enter и получаем вывод.
